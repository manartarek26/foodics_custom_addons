Sending Orders to Foodics

A plain-language explanation of what happens when you click "Send to Foodics", and why there's a bit of automatic double-checking going on behind the scenes.

The short version

You open a Sale Order in Odoo, click Send to Foodics, and that order gets created inside Foodics for the branch you picked - the same as if a cashier had rung it up there directly. From that point on, Odoo keeps a little "tracking card" for that order (a Foodics Order record) and tries to always know what's really happening to it on Foodics' side, even if something goes wrong along the way.

Step by step

You click "Send to Foodics"
→
Odoo builds the order
→
Odoo sends it to Foodics
→
Foodics confirms it arrived

Odoo takes the products on your Sale Order, matches them to the equivalent products on the Foodics menu, and picks a branch that's allowed to receive online orders. If a product on your order hasn't been approved/linked as a Foodics product yet, Odoo stops and tells you exactly which one, instead of sending a half-broken order.

What the status on the order means

StatusWhat it means, in plain terms
DraftCreated in Odoo, not sent yet.
PendingSent to Foodics successfully - it's now sitting there waiting for the restaurant to accept or decline it.
ActiveThe restaurant accepted it and is working on it.
ClosedFinished and paid for.
Declined / VoidThe restaurant rejected or cancelled it.
ReturnedThe order was returned after being closed.
Error SendingOdoo tried to send it but something went wrong (see below).

How Odoo finds out the status changed

Once an order is sitting on Foodics' side, things happen to it that Odoo isn't directly involved in - a cashier accepts it, prepares it, closes it. Foodics tells Odoo about these changes itself, automatically, the moment they happen, using something called a webhook - think of it as Foodics picking up the phone and calling Odoo to say "hey, order #123 just got accepted", instead of Odoo having to keep calling Foodics every few seconds to ask "anything new? anything new? anything new?". This is why the status usually updates itself without anyone doing anything.

...and what happens if that call never comes through

Phone calls sometimes don't go through - a brief internet hiccup, a server restart, anything. If Foodics tried to tell Odoo about a change and the message never arrived, the order would just sit there showing an outdated status forever, with nobody noticing.

The safety net: every 15 minutes, Odoo quietly checks in on any order that hasn't been confirmed recently, and asks Foodics directly: "what's the real status of this one?" If it finds a mismatch, it fixes the record automatically. You don't have to do anything for this to happen - it's a scheduled task that just runs in the background (Settings > Technical > Scheduled Actions > "Foodics: Reconcile Pending Orders", if you ever want to look at it or change how often it runs).

If you ever want to check right away instead of waiting, open the order and click Refresh Status from Foodics.

"Needs Reconciliation" - what does that mean?

Occasionally, when Odoo sends an order, the request itself fails to complete properly (a timeout, a dropped connection) before Odoo gets a clear answer back. In that moment, Odoo genuinely doesn't know whether Foodics received the order or not. Rather than guess - and risk either creating the same order twice, or thinking it failed when it actually succeeded - Odoo flags the order as "Needs Reconciliation" and asks Foodics directly what really happened, either right away or on the next automatic check.

You'll see a small warning banner on the order when this flag is set. It's informational - it clears itself as soon as Odoo has confirmed the real status, either by the automatic check or by clicking "Refresh Status from Foodics" yourself.

One safeguard worth knowing about: every order gets a unique ID the moment it's created in Odoo, before it's ever sent. If Odoo tries to send the same order a second time (say, after that kind of failed attempt), Foodics recognizes the ID and says "you already sent me this one" instead of creating a duplicate. Odoo treats that response as a signal to go check the real status, not as a new error.

Frequently asked questions

Do I need to do anything after clicking "Send to Foodics"?
No. The status will keep itself up to date on its own. Check the order later if you're curious, but nothing is required from you.
What if I see "Error Sending"?
Open the order to see the error message - usually a missing product mapping or a branch that isn't accepting online orders. Fix that, then click "Push to Foodics" again from the order.
What if a status looks stuck or wrong?
Click "Refresh Status from Foodics" on the order to check right now, instead of waiting for the next automatic check.
Can an order get sent to Foodics twice by mistake?
No - see the safeguard above. Clicking "Send to Foodics" again on an order that already went through successfully won't create a second one.
